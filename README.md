# 待做事项 · Todo Board（`dsh-todo-board`）

中文 | [English](README.en.md)

一个给 DSH Web 界面用的个人待办板，画成贴在一个月历上的便利贴：淡彩纸、胶带、轻微倾斜、印刷体衬线（Georgia 配宋体/SimSun），再加一个橡皮图章式的计数。它提供三块界面：

| 界面 | 作用 |
|---|---|
| `sidebar.panellist` | 侧栏一个清单图标；还有未完成任务时图标上带一个小圆点。点击打开面板。 |
| `main`（key 为 `todo-board`） | 月历，便利贴钉在日期上；下方是当天的便利贴列表（添加、完成、编辑、删除、改期、清除已完成），板子上方还有一个番茄钟专注倒计时。 |
| `conversation.input.dock` | 输入框上方可折叠的待完成摘要：未完成数量、下一条任务、以及前几条可直接勾选的行。全空时自动隐藏；计时进行中会在旁边显示专注时间。 |

## 番茄钟专注计时

板子顶部的纸卡里是一个专注倒计时：手绘的圆环、剩余时间、以及当前阶段（专注 / 小憩 / 长休息）。点「开始专注」启动；卡片可以折成一行细条，这个选择会被记住。

- 时长可选 15 / 25 / 50 分钟（默认 25）。一段专注结束自动进入 5 分钟小憩；每完成第四段专注换成 15 分钟长休息；休息结束后等你确认才开始下一段专注。
- 可以把一张便利贴连到这一轮（`连一张便利贴`）；专注结束时卡片会问这张贴是否完成，一键勾掉。
- 每个阶段切换会响一段三音柔和提示音（可静音），卡片上还统计今天完成的番茄数。
- 「重置」重放当前阶段，「跳到下一段」跳过且不计番茄。
- 运行中的计时同时显示在输入框上方，两处读同一个时钟。
- 计时状态存在 `localStorage`（`todo-board.pomodoro.v2`）里，存的是绝对截止时间，所以刷新页面或后台标签被节流后仍然报正确的剩余时间。计时数据不会发到宿主侧。

## 日历与日期

每条任务可带一个 `dueDate`（`YYYY-MM-DD`，本地日历日）。页面打开在当月并选中今天；日历每天最多显示两条便利贴（其余显示 `+N`），点某一天会把下方列表切到那天。把便利贴卡片拖到某个格子上即可钉到该日，也可以先点卡片再点日期。`未排期` 区块收集没有日期的贴，把贴拖进去即可取消日期。输入框里的日期字段默认今天；清空它就会创建一条未排期任务。

## 内置字体

`fonts/ChenYuluoyan-Thin.ttf`（辰宇落雁體，SIL OFL 1.1，保留了字体名）由宿主侧以 `GET /todo-board/font/<文件名>` 提供（公开资源、不可变缓存），并出现在 `Aa` 字体菜单里。授权与署名见 `fonts/NOTICE.md`。

另有一款手写体（我爱万伟伟手写体）**不随本仓库分发**：该字体自身没有版权与许可声明，来源站点也说明商业使用需联系原作者，所以只在作者本机保留。仓库里没有这个文件时，字体菜单中的该项会回落到楷体显示。

## 数据存在哪里

浏览器半边从不自己存任务。它调用宿主侧注册的两条同源路由：

- `GET /todo-board/state` —— 当前列表
- `POST /todo-board/mutate` —— 一次一个操作：`add`、`toggle`、`edit`、`remove`、`schedule`、`clearDone`

两条路由都要过 Web 载体的信任校验（`ctx.connection.requestRejection`），否则回 `401`/`403`。状态是单个 JSON 文件，位于 `<dsh home>/todo-board/state.json`（例如 `~/.dsh/todo-board/state.json`），以原子写落盘，所以列表能扛住刷新、重启、GUI 端口变化，以及同一 Harness home 下的另一个浏览器。文件格式是 version 2（version 1 的记录会直接读成未排期）。

每个宿主进程同时只跑一个操作；状态文件损坏时会被移到一边（`state.json.corrupt-<时间戳>`）而不是被覆盖。

## 安装

```
dsh plugin add github:serein772/dsh-todo-board
```

也可以直接在插件市场里找。本地开发时，把 profile 依赖用 `link:` 指向这个目录即可。

两个半边都是纯 JavaScript，没有构建步骤；宿主侧的一行配置加上 `package.json` 里的 `dsh.client` 声明，就是这个插件需要的全部接线。
